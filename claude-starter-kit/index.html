Claude for Teams · advocacia · começando do zero

Verena, comece por aqui.

Este não é um manual de IA. É um passo a passo para você usar Claude no trabalho jurídico sem precisar entender tecnologia.

Primeiro resultado em ~15 min · Windows · Sem programação

1. Faça isso agora

Nada de configurar um sistema complexo. Abra Claude e faça uma tarefa real.

1
Entre no workspace Team do escritório. Não use uma conta pessoal para material profissional.
2
Pegue uma peça simples. Preferencialmente algo já protocolado/público ou expressamente permitido pela política do escritório.
3
Anexe no Chat. Clique em + → adicionar arquivo.
4
Escreva:
Leia este documento como uma advogada de contencioso. Explique o que aconteceu, os principais argumentos, os pontos que merecem minha atenção e o que você não consegue concluir com segurança. Cite a página quando fizer uma afirmação importante.
5
Converse com a resposta. Pergunte “onde está isso?”, “isso é fato ou inferência?”, “qual é o melhor argumento contrário?”.
Se você só fizer isso hoje, ótimo. O objetivo é sentir como Claude trabalha antes de organizar qualquer coisa.

2. Você só precisa entender 3 coisas

todo diaChatUma conversa. Use para ler, revisar, comparar, escrever e pensar junto.
um por casoProjectUma sala dedicada a um processo/arbitragem. Claude mantém ali o contexto daquele caso.
tarefas grandesCoworkVocê entrega uma pasta e um objetivo; Claude executa várias etapas e trabalha com arquivos.
Ignore Claude Code. Você não precisa dele para começar — nem de terminal, MCP, RAG ou qualquer outro termo técnico.

3. Crie o primeiro Project de um caso

Depois de testar o Chat, crie 1 Project para 1 caso. Não misture clientes.

Coloque poucos documentos no começo

  • contrato principal e aditivos relevantes;
  • Request for Arbitration / inicial;
  • Answer / contestação;
  • última peça relevante de cada lado;
  • procedural orders importantes;
  • chronology existente, se houver.

Copie estas Project Instructions

Este Project é sobre [CLIENTE] v. [PARTE CONTRÁRIA].
Nós representamos [CLIENTE].
Instituição/foro: [___]
Lei aplicável: [___]
Estágio atual: [___]

Nunca invente fatos ou fontes.
Diferencie fato comprovado de alegação.
Cite documento e página sempre que possível.
Avise quando não conseguir concluir algo.
Procure também fatos e argumentos contrários à nossa posição.
Não suba 2.000 documentos. O Project começa pequeno. O restante entra conforme o trabalho exigir.

4. Reúna todos os documentos de cada caso em uma pasta

Aqui entra a organização. A ideia é simples: 1 caso = 1 pasta no Windows. Tudo que estiver espalhado vai primeiro para uma pasta de entrada.

Crie assim

C:\Casos\Acme v Beta\
├── 00_ENTRADA\
├── 01_PECAS\
├── 02_CONTRATOS_E_DOCUMENTOS_CHAVE\
├── 03_PROVAS\
├── 04_TESTEMUNHAS_E_PERITOS\
├── 05_PROCESSUAL\
├── 06_PESQUISA\
└── 90_OUTPUTS_CLAUDE\

O único lugar que você precisa lembrar é 00_ENTRADA. Achou um arquivo do caso? Jogue ali. Depois Claude organiza.

De onde vêm os documentos?

FonteO que fazer
HD / Downloads / DesktopCopie o que parece ser do caso para 00_ENTRADA. Se usar Cowork, conecte somente as pastas necessárias.
OutlookSe o Microsoft 365 estiver conectado, peça ao Claude para procurar emails pelo nome das partes, número do caso, domínio e período. Baixe os anexos relevantes para 00_ENTRADA quando necessário.
OneDrive / SharePointClaude pode pesquisar o que você já tem permissão para acessar. Se quiser um corpus local único, copie/sincronize apenas os arquivos do caso para 00_ENTRADA.
iManage / NetDocuments / outro DMSSe não houver integração aprovada, exporte os documentos selecionados para 00_ENTRADA. O DMS continua sendo a fonte oficial.
Não conecte o HD inteiro ao Cowork. Dê acesso somente à pasta do caso e, quando necessário, à pasta-fonte onde você quer que ele procure.

5. Instale uma Skill que organize a pasta para você

Uma Skill é apenas uma instrução reutilizável. Em vez de ensinar toda vez “como eu quero que você organize meus casos”, você ensina uma vez e Claude reaplica.

Instale a Skill pronta

Baixar “Organizador de Caso”
  1. No Claude, vá a Personalizar → Skills.
  2. Clique em + → Criar skill → Carregar uma skill.
  3. Escolha o ZIP acima.
  4. Deixe a Skill ativada.
  5. Se Skills não aparecer, peça ao owner do Team para confirmar que Skills + execução de código/criação de arquivos estão habilitadas.
No Windows: hoje você não consegue “gravar” uma Skill automaticamente pelo Cowork como no Mac. O caminho simples é upload do ZIP.

Depois, para organizar um caso, diga só isto

Organize a pasta deste caso.

Primeiro inventarie o que já existe. Depois organize 00_ENTRADA nas pastas corretas, sem apagar nem sobrescrever originais.

Crie um índice. Identifique duplicatas, versões antigas e arquivos cuja classificação é incerta.

Se o Microsoft 365 estiver conectado, procure também emails e documentos relacionados ao caso. Para qualquer anexo que você não consiga salvar automaticamente, faça uma checklist para eu baixar.

O que a Skill faz

  • separa documentos por tipo;
  • cria um índice CASE_INDEX.md;
  • identifica duplicatas e versões;
  • lista documentos encontrados fora da pasta;
  • faz checklist de anexos de email que faltam;
  • aponta possíveis lacunas do record.

Como criar qualquer outra Skill

Quando perceber que está repetindo uma tarefa, peça ao próprio Claude:

Quero transformar este workflow em uma Skill do Claude.

Crie uma Skill simples, sem código, com um arquivo skill.md.
Ela deve dizer:
- quando deve ser usada;
- quais inputs precisa;
- passo a passo;
- regras que nunca pode violar;
- output esperado.

Empacote em um ZIP pronto para eu carregar em Personalizar → Skills.

Skills funcionam melhor quando cada uma resolve uma tarefa específica. Não tente criar uma “Skill que faz tudo”.

6. Como pedir coisas para Claude

Esqueça “prompt engineering”. Delegue como delegaria para um advogado mais júnior.

Contexto+O que você quer+Quais documentos+Como quer receber

Ruim

Analisa essa petição.

Bom

Representamos a Claimant. Este é nosso draft de Reply. Antes de eu mandar para o sócio, quero descobrir fragilidades. Leia o draft e a Defence anexada. Liste primeiro os 10 principais problemas, com página e explicação. Não reescreva ainda.

Frases úteis

  • “Onde exatamente está isso no documento?”
  • “Isso é fato ou uma inferência sua?”
  • “Qual é o melhor argumento contra essa conclusão?”
  • “O que estou deixando de perceber?”
  • “Não reescreva ainda. Primeiro critique.”

7. Dez prompts jurídicos prontos

Abra apenas o que precisar. Copie, adapte os nomes e use.

01Entender uma peça+ 
Leia este documento como uma advogada de contencioso. Explique: (1) o que aconteceu; (2) os principais argumentos; (3) os pontos que merecem minha atenção; (4) o que você não consegue concluir com segurança. Cite a página sempre que fizer uma afirmação importante.
02Comparar duas peças+ 
Compare estes dois documentos. Monte uma tabela com: tema, posição do Documento A, posição do Documento B, o que mudou, contradições ou pontos não respondidos e relevância prática. Depois indique os 5 pontos que eu deveria olhar primeiro.
03Montar uma cronologia+ 
Leia os documentos anexados e monte uma cronologia. Para cada evento: data, o que aconteceu, pessoas envolvidas, documento-fonte, página/seção e por que importa. Diferencie fato documentado de mera alegação. Não preencha lacunas por suposição.
04Revisar uma petição+ 
Revise este draft como um advogado sênior exigente. Primeiro NÃO reescreva. Aponte argumentos confusos, fatos sem suporte, repetições, saltos lógicos, argumentos da contraparte não respondidos e trechos que exageram a evidência. Organize por prioridade. Só depois proponha alterações.
05Red team da tese+ 
Atue como advogado da parte contrária. Faça o ataque mais forte possível ao nosso argumento: fatos contrários, premissas frágeis, inconsistências, interpretações alternativas e perguntas difíceis do tribunal. Depois volte ao nosso lado e proponha respostas.
06Preparar testemunha+ 
Analise somente os documentos relacionados a esta testemunha. Prepare: cronologia pessoal, documentos enviados/recebidos, decisões e reuniões, possíveis inconsistências, fatos dentro do conhecimento pessoal e perguntas para a entrevista. Diga qual documento motivou cada pergunta. Não invente memória.
07Preparar cross-examination+ 
Compare o witness statement com documentos, pleadings e demais materiais. Para cada ponto útil: o que queremos estabelecer, documento/declaração anterior, contradição, sequência curta de leading questions, risco de explicação e recomendação usar/reservar/descartar.
08Document production / Redfern+ 
Analise cada document request. Explique o que a outra parte procura, qual issue pretende provar, riscos de amplitude/ambiguidade/proporcionalidade, possíveis objeções, custodians/fontes prováveis e informação que falta. Não redija a objeção final ainda.
09Pesquisa jurídica verificável+ 
Ajude-me a pesquisar esta questão jurídica. Não invente casos, citações, números ou quotes. Prefira fontes primárias. Marque claramente qualquer autoridade não verificada. Entregue resposta curta, autoridades, links/fontes, posição contrária e o que ainda precisa ser pesquisado.
10Fechar uma sessão+ 
Resuma esta sessão para eu retomá-la amanhã: tarefa, documentos usados, conclusões importantes, pontos a verificar, decisões tomadas, próximos passos e arquivos/versões a salvar. Sinalize quando algo for inferência e não fato documental.

8. Privacidade: a regra simples

Claude for Teams é produto comercial. A Anthropic informa que, por padrão, inputs e outputs dos produtos comerciais não são usados para treinar os modelos.

Isso não significa “pode subir tudo”. A regra do escritório, as instruções do cliente, privilege, LGPD e regras do caso continuam valendo.
  • use sempre o workspace Team;
  • confirme a política de IA do escritório;
  • suba apenas o que precisa;
  • para material extremamente sensível, privileged, segredo comercial ou dado pessoal sensível, confirme a autorização antes;
  • não dê ao Cowork acesso a pastas de outros clientes.

9. No Windows

  • Claude Desktop funciona no Windows 10 ou superior;
  • para Cowork trabalhar plenamente com arquivos locais, o Windows pode precisar da Virtual Machine Platform habilitada;
  • em notebook corporativo, TI pode precisar instalar/habilitar isso;
  • arquivos locais só ficam acessíveis ao Cowork enquanto o Desktop está aberto e a sessão tem a pasta conectada.
Não precisa configurar Cowork no primeiro dia. Chat no browser já é suficiente para começar.
